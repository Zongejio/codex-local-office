# 运维

## 检查

日常无需输入命令。正常从文件插件打开时会自动检查并启动本机服务。安装位置记录在应用数据目录的 `last-install.json`，诊断日志在 `service.log`。开发者可在该安装位置使用随安装器下载的 Node 运行 `scripts/doctor.mjs`；它只读检查，不启动服务。

固定端口为 43228（本地 Docs）、43232（保存服务）、43233（localhost TLS）。端口冲突时安装器停止，不会关闭其他应用。如果先前安装未完成，请重新运行安装器；它保留已有密钥、数据和虚拟机，已安装的 ONLYOFFICE 不重复安装。

## 停止

先保存所有打开文件，并确认顶部提示已保存，再关闭编辑器。

```bash
office_lima="$(cat "$HOME/Library/Application Support/CodexLocalOffice/runtimes/lima-2.2.1.path")"
LIMA_HOME="$HOME/.codex-office-vm" "$office_lima/bin/limactl" stop codex-office
```

这会停止占用内存较多的本地编辑引擎，保留所有文件。轻量 Node 保存服务可能继续运行；不要用批量结束 Node 进程的方法停止它，以免影响其他应用。后续再次打开文件会启动引擎。

## 更新

升级前先保存并关闭全部编辑器。下载新版 ZIP，解压后双击安装，插件注册也会自动完成。每次安装创建独立程序目录并保留旧目录、配置备份；不要删除应用数据目录。安装器不会主动结束已有后台进程，更新后的运行代码最迟在相关后台服务下次启动时生效。自动更新、签名安装包、证书续期向导尚未提供。

## 证书

证书仅用于 localhost。如果系统没有信任，重新运行安装器并明确确认信任步骤。不要关闭浏览器安全检查。证书即将到期时安装器会停止；目前需备份并人工维护，不能直接删除整个 private 目录，因为其中还有正在使用的文档签名密钥。

## 磁盘与卸载

历史编辑和修改前备份不自动清理。在决定清理前先检查原文件已保存，并明确选择要删除的会话目录。该版本没有自动清理或一键卸载脚本，避免误删文件。

只想停用时，在 Codex 中禁用插件并停止虚拟机。完整卸载涉及插件、生成配置、VM、证书信任及备份，必须逐项确认范围；保留数据不会影响原文件。
