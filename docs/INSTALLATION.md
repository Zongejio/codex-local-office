# 下载后安装

1. 下载 Release 页面里名字以 `.zip` 结尾的安装包，双击解压。
2. 打开 `Office-Local-Editor` 文件夹，双击 **双击安装.command**。
3. 点击“开始安装”，等待下载及安装完成。在本机证书确认出现时，确认后继续。
4. 安装完成后保存 Codex 中的工作，退出并重新打开一次 Codex。首次对 Word、Excel、PPT 各选择一次“Office 本地编辑器”。

不需要输入命令，不需要安装 Homebrew、Node.js、Lima 或 Codex CLI，不需要填写密钥或服务器地址。你只需要事先安装兼容插件功能的 Codex 桌面版。

安装会打开一个显示进度的终端窗口；无需向里面输入任何命令。下载完成前请保留窗口。首次下载可能数 GB，速度取决于网络。

## 系统可能提示什么

当前安装包没有 Apple Developer ID 签名及公证。下载到另一台 Mac 后，系统可能要求确认是否打开，或在系统设置中审核该下载项目；不能保证每台 Mac 都能直接双击运行。只在确认下载来源为本项目 GitHub 发布页时批准打开。安装器不会关闭 Gatekeeper、删除隔离标记或绕过系统检查。

本机证书只用于 `localhost`，不是通用 CA。安装时会明确请求同意，再调用系统钥匙串机制。拒绝时停止后续步骤，已有文件保留。

## 自动完成的工作

- 下载固定版本的官方 Node.js 与 Lima，检查已固定的 SHA-256；不改系统环境，不使用 Homebrew，不启动 Docker。
- 将程序复制到应用数据目录，下载包以后不再是运行依赖。
- 安装本地 Office 引擎，为本机生成密钥和证书。
- 检查服务并自动注册 Codex 插件，不需要单独安装或配置命令行工具。
- 升级时保留旧程序目录和配置备份，不自动删除用户文件。

运行目录：`~/Library/Application Support/CodexLocalOffice/`；虚拟机目录：`~/.codex-office-vm/`。

## 中断与重试

网络中断、证书未确认或 Codex 注册失败时，会提示安装未完成；不会把失败写成成功。重新双击安装文件即可重试。已校验的运行环境下载会复用，旧目录保留，不自动清理。

安装完成不会自动重启 Codex，以免影响未保存的工作。默认打开方式仍由 Codex 管理，安装器不会偷偷改写文件关联。
