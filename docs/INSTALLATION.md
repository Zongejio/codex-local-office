# 安装和使用

## 下载

**[点击下载 Mac 安装包](https://github.com/Zongejio/codex-local-office/releases/download/v0.6.0/Office-Local-Editor-0.6.0-Mac-Notarized-1792921268283.zip)**

只适用于 Apple 芯片 Mac、macOS 14 及以上。普通用户不用下载发布页的 `Source code` 或 `.sha256`。

## 安装：解压 → 双击 → 开始安装

1. 双击 ZIP 解压。
2. 双击 **Office Local Editor Installer.app**，点击 **开始安装**。
3. 出现系统打开确认或本机证书授权时，按提示确认。
4. 等到安装成功，再保存工作并重新打开 Codex 一次。

无需输入命令、自己安装运行环境或填写服务器地址。首次安装会下载数 GB 组件，请保持联网并保留安装窗口。建议至少 8 GB 内存、40 GB 可用磁盘空间。

## 打开：点文件 → 选择编辑器

在 Codex 聊天中点击本地 `.docx`、`.xlsx` 或 `.pptx` 文件。

首次使用若打开只读预览，选择 **打开方式 → Office 本地编辑器**。Word、Excel、PPT 各设置一次。之后如果 Codex 没有记住，仍可从这个菜单打开。旧版 Codex 若没有插件打开方式，需要先更新 Codex。

完整编辑器会在 Codex 浏览器标签页打开。若保留了一个启动页，它可以关闭，不影响保存。

## 保存：点击“保存到文件”

修改后点击页面顶部 **保存到文件**，等到 **已保存到本地原文件**，再关闭编辑器。

编辑器内部的自动保存提示不代表已经写回电脑原文件。文件冲突时不要强行覆盖，先核对其他软件对原文件的修改。

## 遇到问题

| 看到的情况 | 怎么做 |
| --- | --- |
| 只读预览、不能编辑 | 从文件“打开方式”选择 Office 本地编辑器 |
| 首次启动较慢 | 等待本机编辑引擎启动，不要反复点击 |
| 安装下载失败 | 检查网络，重新打开安装应用重试 |
| 拒绝了证书授权 | 安装会停止；愿意授权时再重新安装 |
| 文件保存冲突 | 核对原文件和保留的编辑版本，避免覆盖他人的修改 |
| macOS 提示安装包无法验证或已损坏 | 从上方官方发布链接重新下载；仍失败时提交报错，不要关闭系统安全检查 |

安装包已通过 Apple 签名和公证，仍可能出现下载应用首次打开确认。本机证书仅用于电脑上的 `localhost` 连接，需要你确认，不会自动关闭系统安全保护。

程序和数据保存在 `~/Library/Application Support/CodexLocalOffice/`；虚拟机在 `~/.codex-office-vm/`。安装后下载包不再承担运行职责。不需要云服务器，不启动 Docker；旧程序和文件副本会保留。
